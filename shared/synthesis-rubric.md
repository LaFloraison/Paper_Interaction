# 综合门 rubric —— 全站验收标准（v5 新增，用户 2026-10-08 定稿）

**为什么需要它**：读者门是**盲的**——一卡一代理，代理看不到别的卡。它能保证"每张卡自己讲清楚了"，但保证不了两件事：
1. **卡与卡之间是否打架**（同一数字两说、同一术语两义、某卡习题答案与别卡例子冲突）；
2. **整站是否真的讲透了这篇论文的来龙去脉**，读完能否对领域有综合理解。

综合门在这两处补洞。**全站卡片通过读者门之后跑**，两个代理，各自独立。

---

## 代理 A · 全局一致性审

**输入**（构建器产出，不给人读原文）：全站卡片摘要表 —— 每卡：卡号 / 章 / 节 / 标题 / 定义盒文本 / 出现的公式 / 全部习题题干与正确答案 / data-answer 值；外加**已验证数值总账**与**论文原表的数字**。

**不需要**给代理看卡片正文（它做的是交叉核对，不是文笔评审）。

**检查清单**

| # | 检查项 | 例子（v4 实战中出现过的真事故） |
|---|---|---|
| A1 | **跨卡数字矛盾** | 卡 X 的解析引用了卡 Y 的一个错误中间值 |
| A2 | **术语一致性** | 同一概念两处两种叫法或两种译法（"规则账 / 规则矿 / rule ledger"混用） |
| A3 | **习题答案 vs 别卡内容** | 某卡习题的正确答案，与另一卡例子算出的数不一致 |
| A4 | **卡片 vs 论文原表** | 卡片复述论文数字时抄错，或与表格口径不同（如度数口径、平均排名） |
| A5 | **重复讲解** | 同一概念在两处各自从零讲起（应一处讲、另处回指） |
| A6 | **悬空回指** | 卡 A 说"见卡 B 的结论"，而卡 B 没有那个结论 |
| A7 | **数值链条完整性** | 正文里出现却没有进入"已验证数值"总账的数字 |

**输出格式**

```
verdict: PASS / FAIL
矛盾清单（逐条）：
  [编号] 卡 X ↔ 卡 Y | 类型（A1–A7）| 引原句双方 | 哪个对（给判据）| 改法
悬空/重复清单：...
无法判断项：需要回到论文原文核对的条目
```

**判据优先顺序**：论文原表/原文 > 已验证数值总账（Python 复算） > 卡片正文。卡片与表格冲突时，**以表格为准并标注**（v4 的审计经验：正文常有笔误）。

## 代理 B · 领域考官审（来龙去脉 + 综合理解）

**设定**（派代理时原样置入）：

```
你是这个子领域的资深研究者/博士答辩委员。你已经精读过这篇论文，也熟悉它所在的文献脉络。
现在有人把一份"论文学习网站"的大纲交给你——只有章节结构、每张卡的标题和定义句，
没有卡片正文。你要判断的不是"写得好不好"，而是"读完这套东西的人，是否真的懂了这件事的来龙去脉，
是否对这个领域有了综合性的理解，而不只是会复述这一篇"。
【不要客气】。缺口就说缺口——那正是这套材料最需要补的地方。
```

**输入**：论文原文（PDF 文本）+ 全站大纲（7 章结构 + 节 + 每卡标题与定义句 + 拓展小节清单 + 引用清单）。**不给卡片正文**——这样代理判的是**覆盖**，不是文笔。

**四问（必须逐问作答）**

1. **覆盖账（新增，第一必答项）** — 逐节列出论文的每一节，标出站点里覆盖它的卡片编号；**对不上账的段落就是缺口**（论文有，卡片没有 = 违反第一原则判据 1）。原文的论断、图表、公式都要有落点。
2. **谱系** — 这篇论文从谁来？指出 3–5 篇直接前身（谁定义了它要解决的问题、它直接改进谁）。它改了什么？它之后谁延伸了这条路（若已知）？
3. **从业者决策** — 在这个子领域里做事的人，要在哪些点上做选择？（如：超边怎么构造、要不要考虑顶点度、inductive 还是 transductive、评测协议怎么定）本文各如何选？**替代方案是什么、代价是什么**？
4. **残留无知** — 读完全站，我仍然不知道什么？（方法细节？失效条件？与同期工作的对比？）
5. **裁决** — 若我是这个方向的新博士生，这站是否足以让我：(a) 准确复述这篇论文 (b) 向别人解释它为什么重要 (c) 在组会上有理有据地质疑它？逐项给 是/否 + 理由。

**输出格式**

```
verdict: PASS / FAIL（覆盖账有缺口、或四问缺口过多、或裁决有"否"即 FAIL）
覆盖账：论文节 → 卡片编号列表；缺口语段逐条列出
谱系回答：...
从业者决策回答：...
残留无知清单（逐条）：
缺口清单（可操作）：
  [缺口] 陈述 | 建议补法（新增拓展小节 / 新增引用卡 / 扩充某卡 / 新增习题卡）| 预计卡数
裁决：复述 是/否 · 解释重要性 是/否 · 组会质疑 是/否
```

**缺口转卡**：缺口清单逐条转成新卡——拓展卡（概念/家族）、引用卡（承重文献）、或原卡扩充。新增卡片**同样要过读者门**。综合门可迭代：补完卡后可再跑一次 B（可选，通常一次足够）。

## 与读者门的分工（不要混淆）

| | 读者门 | 综合门 |
|---|---|---|
| 视野 | 一张卡 | 全站 + 论文 |
| 代理设定 | 未读过本文的名校本科生 | 读过本文的领域资深研究者 |
| 抓什么 | 术语裸奔、定义缺失、例子算不动、习题不达标 | 跨卡矛盾、覆盖不全、来龙去脉不清 |
| 何时跑 | 每章写完后（并行） | 全站通过读者门后 |
| 产出 | 逐卡 PASS/FAIL | 矛盾清单 + 缺口清单 |
