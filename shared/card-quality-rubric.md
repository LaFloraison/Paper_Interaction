# 卡片质量 rubric —— 读者门评分标准（v5，用户 2026-10-08 定稿）

**用途**：① 生成卡时逐项自检；② 读者门审卡子代理按本文评分。三轴：**讲解（是什么）/ 例子 / 习题**。
**规则**：任一轴出现硬伤 = 该卡 **FAIL** → 重写 → 重审。
**v5 核心变更**：废除全部字数/句数/术语数上限，改为**四条硬判据**（完整性 / 自足性 / 定义优先 / 清晰性）。**篇幅服从清晰，不是相反。** 讲解不清晰、例子不明确、习题不达标 = 垃圾，禁止交付。

---

## 审卡代理设定（派代理时必须原样置入）

```
你是一个审卡读者，设定如下，全程不得脱离：
- 顶尖名校本科生 / 未来的学者。数学成熟，读得懂公式与证明，严肃、严谨，想真懂。
- 但你【没有读过这篇论文】，也【可能没学过这张卡讲的话题】，不了解这个子领域的历史。
- 你只看得到下面这一张卡的内容（渲染后的文字与公式）。看不到论文原文、看不到其他卡片、看不到蓝图。
- 请【诚实】——卡在哪里就说卡在哪里，看懂了就说看懂了。不要客气，不要脑补作者意图，不要替作者补上他没写的东西。
- 遇到没定义就使用的术语、算不下去的例子、答不出的习题，如实记录——这些是作者的问题，不是你的问题。
- 【不要因为篇幅长就扣分】。写得长而清楚是好卡；写得短而漏掉关键环节是坏卡。你的唯一标准是"我是否真懂了"，不是"它是否够短"。

审完按文末格式输出 verdict。
```

## A 轴 · 讲解（是什么段）

| # | 检查项 | 硬伤信号（触发即 FAIL） | 警告信号 |
|---|---|---|---|
| A1 | 一卡只承担一个自足的讲解单位 | 出现第二个需要独立解释的核心概念，且未拆到别卡 | 边界模糊（读者说不清这卡在讲什么） |
| A2 | **定义优先**：定义盒（正式定义 + 白话重述）出现在卡首 | 读完"是什么"段仍说不出这东西的正式定义；定义盒缺失；白话重述里仍有未解释的行话 | 正式定义里有关键术语没就地括注 |
| A3 | **未定义的术语不许出现**——每个术语首次使用处必须已有定义（或显式回指某卡） | 术语裸奔（如 logit / 梯度 / 置换不变性 / 超边 未定义就使用）；用 A 解释 B 而 A 也没定义 | 定义离使用处太远 |
| A4 | **完整性四问**：读完能回答 为什么需要它 / 它是什么 / 它怎么运作 / 它何时失效 | 四问任一答不上（尤其"何时失效"最常见缺） | 边界讨论泛泛 |
| A5 | 公式最后出场；每个符号能答"从哪个直觉来" | 符号念一遍无直觉对应；公式先于直觉出现；符号未定义就出现在公式里 | 符号解释与公式分离过远 |
| A6 | 遮公式测试：删掉公式，文字仍能自足表意 | 删公式后句子失去意义 | — |
| A7 | **自足性**：需要的结论就地重述或显式回指 | 出现"如前所述 / 上文提到"而读者无从回翻；依赖未给的前提 | 回指写了但没有足以理解的复述 |
| A8 | 因果链无跳步 | "显然 / 易得 / 可以证明"式跳步 | — |
| A9 | 点破 ≥1 个常见误解 | 全卡无误解块 | 误解块泛泛（"别混淆 X 和 Y"却没说人会怎么混） |

> A4 的"何时失效"是 v5 新增硬性要求。只讲什么时候好用、不讲什么时候不灵 = 不完整 = FAIL。

## B 轴 · 例子（例子段）

| # | 检查项 | 硬伤信号 | 警告信号 |
|---|---|---|---|
| B1 | ≥2 个由小到大实例（第 1 个 ≤3 步能上手） | 只有 1 个庞大例子；无难度梯度 | 两例难度无梯度 |
| B2 | **数字全部真实算过**（蓝图"已验证数值"可查 输入→输出） | 任一数字对不上或未验证 | — |
| B3 | 每步展示算术过程 + 为什么这么做 | 只给结果不给过程 | 过程有但不说为什么 |
| B4 | 例子覆盖"是什么"的全部关键特征；覆盖不到的显式声明"本例未展示 X" | 例子与讲解脱节（讲的 A 演示的是 B） | 覆盖不全但未声明 |
| B5 | 关键前提就地重述，不依赖"如上所述/如前所述" | 读者必须回翻前文才能跟上 | 复述过简 |
| B6 | 遮讲解测试：光看例子能猜出规则 | 例子看不懂在演示什么 | — |
| B7 | （图形/表格卡）**逐要素走查**：每个轴、每个子图、每一列都走到 | 跳过要素且未声明；只念结论不读图 | 走查松散 |

## C 轴 · 习题（习题段）

| # | 检查项 | 硬伤信号 | 警告信号 |
|---|---|---|---|
| C1 | **题数由覆盖决定，无上限**：理解 / 应用 / 迁移三层每层 ≥1；每个已知误区 ≥1 道专属题；每个算术变体 ≥1 道 | 缺层；卡里点破过误区却没有对应题；题量明显不足以覆盖本卡内容 | 题目情境雷同、有凑数题 |
| C1b | 卡是否过大（讲解 + 例子 + 习题三样都长）？若是，习题本应单独成卡 | 单卡内容量明显过载，却硬塞在一卡里 | 接近边界 |
| C2 | 题干不引入卡内未讲的概念 | 超纲题 | — |
| C3 | 每个错误选项解析说中"选它的人怎么想的" | 敷衍式反馈（"不对，正确是 X"）；解析与选项矛盾 | 解析正确但没解释错因 |
| C4 | 错误选项来自真实误解，有貌似合理性 | 明显瞎填的陪跑选项 | — |
| C5 | 数值题四件套 answer/tol/hint/sol 齐全；hint 指向错因而非答案；sol 展示完整算式 | 缺件；hint 泄题；sol 与 answer 不一 | — |
| C6 | 应用题数字 ≠ 例子数字（防背答案）；结构可迁移 | 照抄例子数字 | — |
| C7 | 审卡代理先作答再看解析：自己答错/犹豫的题，反馈是否说中其真实思路 | 反馈与其真实错因错位 | — |

## 审卡代理输出格式（必须逐字段）

```
verdict: PASS / FAIL（任一硬伤即 FAIL）
概念复述：用一句白话说这张卡教的是什么，并给出它的正式定义（说不出 = A2 硬伤）
完整四问：这张卡能回答 为什么需要它 / 它是什么 / 它怎么运作 / 它何时失效 吗？逐问作答（缺 = A4 硬伤）
卡点清单：读者视角，逐条列出卡住/困惑/算不动的位置（引原句）
硬伤清单：[轴-编号] 问题 + 具体改法（改哪一句、改成什么样）
习题实测：三道题我各选/算了什么 → 反馈有没有说中我的思路（C7）
例子实测：我逐行重算了例子，第几步算不动/对不上（B2/B3）
篇幅说明：如果这张卡很长但清楚，明确写"篇幅长但不构成问题"；如果因为太短而漏了环节，指出漏了什么
```

## 数值门（生成者自检，先于读者门）

- 卡内**每一个**数字（正文算例 + 习题题干 + answer + tol）用 Python 实际算过；
- 蓝图"已验证数值"节逐条记录：卡号 / 输入 / 算式 / 输出；
- **边写边算禁止**——先算完一张卡的全部数字，再动笔写这张卡。

## 并行审卡纪律

- **一卡一代理**（铁律）：多卡合并会让代理带上上下文，"未读过本文"的设定就假了。
- 一章的卡写完后**一次性并发派出**（单条消息，并发上限 ~10）；收齐 verdict → 并行修 → **只复审 FAIL 的卡**。
- 审卡记录写进蓝图该卡的"审卡记录"行：批次 / verdict / 主要修改。

## 升级规则

- FAIL → 按硬伤清单重写 → 重送审；
- **卡片过大（讲解 + 例子 + 习题三样都长）→ 先把习题拆成独立的习题卡，再考虑拆讲解**；
- 同卡连续 2 次 FAIL → 不是写的问题，是**拆卡粒度**问题 → 回讲解稿把该卡一拆二，重审两卡。
