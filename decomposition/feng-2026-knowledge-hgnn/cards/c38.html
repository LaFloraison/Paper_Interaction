第 18 卡的"传统卷"（transductive）落到实处，就是表 II：每个数据集切成三份——训练（带答案、用于学习）、验证（带答案、用于挑模型）、测试（不带答案、用于打分）。

Card 18's "classic exam" (transductive) lands in Table II: each dataset splits into three parts — training (with answers, for learning), validation (with answers, for model selection), testing (no answers, for scoring).

表 II 保证的规矩：三份互不重叠，且"无标签点"在训练时可以看到特征与连接（只是没答案）——这正是直推设定的定义。另外第 16 卡的老约定在这里沿用：全图 G 仍然参与消息传递。

What Table II enforces: the three parts never overlap, and unlabeled points are visible during training (features and links, just not answers) — precisely the transductive definition. Card 16's old convention also holds: the full graph G keeps participating in message passing.

例子EXAMPLE

走查 1（读 Cora 行并自检）：Cora 行：#V = 2,708、#C = 7、训练 1,625、验证 677、测试 406。自检一：1,625 + 677 + 406 = 2,708 ✓，三份严丝合缝。比例：约 60% / 25% / 15%——每一类都基本按这个比例切（分层抽样），所以小类也不会在测试里缺席。

Walk 1 (read Cora's row and self-check): Cora: #V = 2,708, #C = 7, training 1,625, validation 677, testing 406. Check one: 1,625 + 677 + 406 = 2,708 ✓, a perfect fit. Ratios ≈ 60% / 25% / 15%, applied class by class (stratified), so minority classes never vanish from the test.

走查 2（换一行 + 一处诚实的瑕疵）：Heloc 行：10,459 = 6,275 + 2,615 + 1,569 ✓，同样严丝合缝。但要如实指出：有三行的三份加起来比 #V 多 1 或少 1——Amazon-P：4,590 + 1,913 + 1,148 = 7,651，而 #V = 7,650；Tencent：1,288 + 537 + 322 = 2,147 vs 2,146；ModelNet40：7,387 + 3,078 + 1,847 = 12,312 vs 12,311。这是按百分比切分后四舍五入的常见产物（差 1 个样本），不影响结论——但读表时值得知道：表里的数字不是全部自洽的，验算是最便宜的照妖镜。（第 48 批判卡会把这笔账汇总。）

Walk 2 (another row + an honest blemish): Heloc: 10,459 = 6,275 + 2,615 + 1,569 ✓, equally tight. But honesty requires noting: three rows sum to one above or below #V — Amazon-P: 4,590 + 1,913 + 1,148 = 7,651 vs #V = 7,650; Tencent: 1,288 + 537 + 322 = 2,147 vs 2,146; ModelNet40: 7,387 + 3,078 + 1,847 = 12,312 vs 12,311. Classic rounding artifacts of percentage splits (one sample off) that do not affect conclusions — yet worth knowing: tables are not automatically consistent, and arithmetic is the cheapest detector.
