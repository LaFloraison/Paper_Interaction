是什么WHAT

表 IX 把知识账插给六种超图机器；表 X 做得更绝：把打分机器换成"普通 GNN"（只有两两边、不处理超边的图神经网络），看知识账还能不能涨分。两个新混血型号由此登场：RD-GNN = 知识账 + 普通 GNN、DD-GNN = 融合账 + 普通 GNN（字母 G 从 HGNN 退成 GNN）。

Table IX plugged the ledgers into six hypergraph machines; Table X goes further: swap the scoring machine for a plain GNN (pairwise edges only, no hyperedges) and see whether the ledgers still pay. Two hybrids debut: RD-GNN = rule ledger + plain GNN, DD-GNN = fused ledger + plain GNN (the H drops out of HGNN).

表 X 的行同时装着四代方法：纯特征（MLP、GBDT）→ 纯结构（GCN、HGNN）→ 知识账混血（RD-GNN、DD-GNN）→ 知识账原生（RD-HGNN、DD-HGNN）；最后一行的 Δ_GCN = 两个混血型号里较好者 − GCN。读它等于看一部"演进史"的快照。

Table X's rows hold four generations at once: feature-only (MLP, GBDT) → structure-only (GCN, HGNN) → ledger hybrids (RD-GNN, DD-GNN) → ledger natives (RD-HGNN, DD-HGNN); the last row's Δ_GCN = the better hybrid minus GCN. Reading it is a snapshot of one evolution.
