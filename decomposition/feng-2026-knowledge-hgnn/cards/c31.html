Equation 7 · one tree's column of scores公式 7 · 一棵树的一列得分

式 (7)：内容分 × 位置分 = 一条规则的得分Eq. (7): content × position = one rule's score

是什么WHAT

两份登记都齐了：内容登记说"满不满足"（0 或 1），位置登记说"分量多重"（一个正数）。现在把同一棵树的所有规则逐条算分、排成一列——这就是式 (7)。

Both registries are ready: content says satisfied-or-not (0 or 1), position says how heavy (a positive number). Now every rule of one tree gets scored and lined up — that is Eq. (7).

每条规则的得分 = 内容分 × 位置分；一棵树所有规则的得分按顺序排成的一列，就是这棵树对某个顶点的"编码"——位数等于这棵树的提问点个数。逐个相乘得到什么？两个直觉读法，见下方的"读法"框。

A rule's score = its content × its position; all of one tree's scores in order form that tree's "encoding" of a vertex — as many slots as the tree has question nodes. What does multiplying produce? Two intuitive readings in the box below.

乘出来的数怎么读（两句话）：How to read the product (two sentences): ① 规则被满足（内容 = 0）→ 乘积 0："这条规则把你说清楚了，不留悬账"。② 规则没满足（内容 = 1）→ 乘积 = 位置分："记一笔悬账，越靠根的悬账越大"。所以这一列读作：该顶点在各条规则上"没被解释"的程度清单。 (1) Rule satisfied (content = 0) → product 0: "this rule explains you; no unsettled account". (2) Rule missed (content = 1) → product = the position weight: "an unsettled entry, heavier near the root". So the column reads: the vertex's degree of being unexplained, rule by rule.

逐符号：φri = 第 i 棵树的编码函数；x = 顶点特征串；Ti = 第 i 棵树；每个括号项 = "第 k 个提问点的位置分 × 内容分"；上标 ⊤ 只是"立成一列"的排版记号；|Oin| = 这棵树的提问点个数（第 11 卡数过）。整式一句话：把每对（位置, 内容）乘起来、排成一列。Symbol by symbol: φri = tree i's encoding function; x = the vertex's features; Ti = the i-th tree; each bracket term = "position of question k × content of question k"; the ⊤ superscript just means "stack into a column"; |Oin| = the tree's question count (counted at card 11). The whole line in a breath: multiply each (position, content) pair and line them up.

例子EXAMPLE

例 1（顶点甲的 T₁、T₂ 逐位乘，参数 α=9、β=8）：T₁ 的两条规则在 0、1 层，位置分 = 1.125、1.0；内容分 = 0、0（第 29 卡例 1）→ 逐位乘：1.125 × 0 = 0；1.0 × 0 = 0。T₁ 的输出 = [0, 0]：T₁ 的两个问题全被满足，不留悬账。

Example 1 (vertex A through T₁, T₂, position by position; α = 9, β = 8): T₁'s two rules sit at layers 0 and 1, positions 1.125 and 1.0; contents 0 and 0 (card 29's Example 1) → multiply slot by slot: 1.125 × 0 = 0; 1.0 × 0 = 0. T₁'s output = [0, 0] — both of T₁'s questions satisfied, nothing left unsettled.

例 1 续（T₂ 三位）：T₂ 的三条在 0、1、1 层，位置分 = 1.125、1.0、1.0；内容分 = 1、1、0 → 逐位乘：1.125 × 1 = 1.125；1.0 × 1 = 1.0；1.0 × 0 = 0。T₂ 的输出 = [1.125, 1.0, 0]：前两条是悬账（第一条还挂在根上，分量最大），第三条已被解释。

Example 1, continued (T₂'s three slots): T₂'s three rules sit at layers 0, 1, 1 with positions 1.125, 1.0, 1.0; contents 1, 1, 0 → slot by slot: 1.125 × 1 = 1.125; 1.0 × 1 = 1.0; 1.0 × 0 = 0. T₂'s output = [1.125, 1.0, 0] — two unsettled entries (the first hangs off the root, heaviest), the third already explained.

例 2（换顶点乙 x = (3, 1, 6)，列全变）：T₁ 内容 = 1、0（x₂ ≥ 2？1 ≥ 2 不满足；x₁ ≥ 1？3 ≥ 1 满足）→ [1.125 × 1, 1.0 × 0] = [1.125, 0]；T₂ 内容 = 0、0、0（6 ≥ 5 满足、3 ≥ 2 满足、1 ≥ 1 满足）→ [0, 0, 0]。同一个坐标系里，甲和乙的得分列判若两人——这正是"特征知识"被显式写下来的样子。

Example 2 (switch to vertex B, x = (3, 1, 6); the column reshuffles): T₁'s contents = 1, 0 (x₂ ≥ 2? 1 ≥ 2 missed; x₁ ≥ 1? 3 ≥ 1 satisfied) → [1.125 × 1, 1.0 × 0] = [1.125, 0]; T₂'s contents = 0, 0, 0 (6 ≥ 5, 3 ≥ 2, 1 ≥ 1 all satisfied) → [0, 0, 0]. In the same coordinate frame, A's and B's score columns are night and day — this is feature knowledge written out explicitly.
