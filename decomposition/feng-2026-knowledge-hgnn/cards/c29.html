Equations 4–5 · the content registry公式 4–5 · 内容登记表

式 (4)(5)：内容登记处怎么打勾Eqs. (4)(5): how the content desk ticks boxes

是什么WHAT

第 27 卡说每条规则要登记"内容 + 位置"两份记录。本卡管内容那一份：拿到一个顶点，逐个问"它满足这条规则吗"，把答案记成一个 0 或 1。

Card 27 said every rule logs two records, "content + position". This card handles content: given a vertex, ask one by one "does it satisfy this rule", and record the answer as a 0 or a 1.

内容登记只有一条规矩：若顶点满足规则，记 0；不满足，记 1。论文把这条规矩写成式 (5)，并先给两张"登记表"起了正式名字——合起来就是式 (4)。

The content desk has a single rule: if the vertex satisfies the rule, record 0; otherwise 1. The paper writes this as Eq. (5), and first gives the two registries formal names — together, Eq. (4).

式 (4) 不是一道算式，而是一段"岗位说明"：μc（内容登记表）吃进"一个顶点的特征串 + 一个提问点"，吐出 0 或 1；μp（位置登记表，下一卡的主角）吃进"一个提问点"，吐出一个实数。本卡先把 μc 的活儿干完。Eq. (4) is not a computation but a job description: μc (the content registry) eats "one vertex's feature string + one question node" and emits 0 or 1; μp (the position registry, next card's star) eats "one question node" and emits a real number. This card finishes μc's work.

式 (5) 逐符号：x = 这个顶点的特征串（如 (1, 3, 4)）；o = 一个提问点；ro = 挂在 o 上的那条规则（如"x₂ ≥ 2"）；"满足记 0、否则 1"。不需要计算，例 1 负责全部打勾。Eq. (5) symbol by symbol: x = the vertex's feature string (e.g. (1, 3, 4)); o = one question node; ro = the rule hung on o (e.g. "x₂ ≥ 2"); "satisfied → 0, else 1". No computing needed; Example 1 does all the ticking.

常见误解：Common misconception: 几乎所有初读者都以为"满足记 1、不满足记 0"——恰恰相反。按论文的写法：满足记 0。读作"这条规则没有拖欠你什么"；记 1 读作"这条规则管不住你，还需要别的规则来解释"。第 3 卡的例子已经埋过这个约定，这里是它的正式出处。 Nearly every first-time reader assumes "satisfied = 1, missed = 0" — the opposite holds. In the paper's convention: satisfied → 0, read as "this rule owes you nothing"; a 1 reads as "this rule fails to cover you; other rules must explain you". Card 3 planted this convention; here is its formal source.
例子EXAMPLE

例 1（把 5 条规则逐个打勾）：顶点甲 x = (1, 3, 4)，逐条问：x₂ ≥ 2？3 ≥ 2 满足 → 0；x₁ ≥ 1？1 ≥ 1 满足 → 0；x₃ ≥ 5？4 ≥ 5 不满足 → 1；x₁ ≥ 2？1 ≥ 2 不满足 → 1；x₂ ≥ 1？3 ≥ 1 满足 → 0。登记结果：T₁ 的两条 = 【0, 0】；T₂ 的三条 = 【1, 1, 0】。（这两个小清单正是第 27 卡例 2 的"对、对、不对、不对、对"的正式写法——把"对"翻成 0、"不对"翻成 1。）

Example 1 (tick five rules one by one): vertex A has x = (1, 3, 4). Ask each: x₂ ≥ 2? 3 ≥ 2 satisfied → 0; x₁ ≥ 1? 1 ≥ 1 satisfied → 0; x₃ ≥ 5? 4 ≥ 5 missed → 1; x₁ ≥ 2? 1 ≥ 2 missed → 1; x₂ ≥ 1? 3 ≥ 1 satisfied → 0. Logged: T₁'s two = 【0, 0】; T₂'s three = 【1, 1, 0】. (These two little lists are card 27's "yes, yes, no, no, yes", formally written — "yes" becomes 0, "no" becomes 1.)

例 2（换一个顶点，清单立刻不同）：顶点乙 x = (0, 5, 6)：x₂ ≥ 2？5 ≥ 2 满足 → 0；x₁ ≥ 1？0 ≥ 1 不满足 → 1；x₃ ≥ 5？6 ≥ 5 满足 → 0；x₁ ≥ 2？0 ≥ 2 不满足 → 1；x₂ ≥ 1？5 ≥ 1 满足 → 0。登记结果：T₁ = 【0, 1】、T₂ = 【0, 1, 0】——两个顶点的"被规则覆盖画像"完全不同，这正是"特征知识"的原料。

Example 2 (another vertex, another list): vertex B has x = (0, 5, 6): x₂ ≥ 2? 5 ≥ 2 satisfied → 0; x₁ ≥ 1? 0 ≥ 1 missed → 1; x₃ ≥ 5? 6 ≥ 5 satisfied → 0; x₁ ≥ 2? 0 ≥ 2 missed → 1; x₂ ≥ 1? 5 ≥ 1 satisfied → 0. Logged: T₁ = 【0, 1】, T₂ = 【0, 1, 0】 — the two vertices' "rule-coverage portraits" differ completely; this is the raw material of feature knowledge.
