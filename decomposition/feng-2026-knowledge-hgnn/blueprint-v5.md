### 三个代表性小节的展开（写作时按此粒度）

**E3 超图家族**
1. 总览：为什么"两两成边"不够用（合著、共同购买、一次会议投多篇）
2. 普通图 / 有向图 / 二部图 / 多重图——各自是什么，超图补上了哪个缺口
3. 超图的两种主流定义（集合族 vs 关联矩阵），以及为什么本文选关联矩阵
4. 超边怎么造（一）：从已有关系直接读取（DBLP 合著）
5. 超边怎么造（二）：从特征空间构造——KNN / 团扩张 / 星扩张 / 属性相似，各自代价
6. 超图 → 普通图的三种展开（团展开 / 星展开 / 线图），以及为什么要展开（好套用现成 GNN）
7. 超边构造方式如何影响结果——本文 k=5–20 的经验选择与它的风险

**E6 决策树家族**
1. 总览：一棵树长什么样（内部节点提问、叶节点下结论），为什么它天然可解释
2. ID3：熵与信息增益
3. C4.5：信息增益率、连续值处理、剪枝
4. CART：基尼不纯度、必须是二叉树、可做回归
5. 三者对照表：划分准则 / 取值类型 / 剪枝策略 / 现代使用
6. 剪枝：预剪枝 vs 后剪枝，为什么不做剪枝的树会背答案
7. 决策树的失效模式：过拟合、轴平行切分、外推无能、对特征缩放不敏感
8. 本文里的树是**回归树**（为什么）——以及它的"提问"如何变成规则

**E20 评测协议**
1. train / val / test 划分的三种形态
2. transductive：测试顶点在训练时**可见**（只是标签藏起来）
3. inductive：测试顶点训练时**从未出现**
4. 本文的 "production" 设定到底新在哪（两种考试合并）
5. 为什么同一个模型在两套协议下分数不同；本文哪里混用了这两个数

**合计：拓展约 120 张卡；本文内容约 90 张；站点总计约 200–215 张。**

这意味着 Paper #2 的站点从"一篇论文的讲解"变成"一门以这篇论文为线索的小课"。这正是第一原则要的：补足与训练。
